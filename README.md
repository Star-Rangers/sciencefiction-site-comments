# Star Rangers — Site Comments

This repo has no code — it exists purely to host the [GitHub Discussions](https://docs.github.com/en/discussions) that power reader comments on [*Fian Ilchruinne*](https://github.com/dermot-r-cochran/star-rangers) (the work formerly titled *Star Rangers*; this repo and its organisation keep the old name on purpose), an interactive science-fantasy novel. It is the shared board for every edition of the story that carries comments: fianilchruinne.com, sciencefiction.site, starquest.site, young.fianilchruinne.com and the contemplative editions, so one chapter has one conversation wherever it appears. The Church Space storyline thread has a board of its own, [churchspace-site-comments](https://github.com/Star-Rangers/churchspace-site-comments).

Comments on the sites are powered by [giscus](https://giscus.app), which maps each page to a Discussion in this repo. The threads live in this repo's [Discussions](https://github.com/Star-Rangers/sciencefiction-site-comments/discussions). Looking for the story itself, or the site's source code? Head to **[dermot-r-cochran/star-rangers](https://github.com/dermot-r-cochran/star-rangers)** or fianilchruinne.com.
